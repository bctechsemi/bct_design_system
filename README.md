# BCT Design System

㈜비씨테크(BCT) — 반도체 장비 부품 위탁 생산 전문기업의 디자인 시스템입니다.

| 경로 | 내용 |
|---|---|
| `index.html` | 디자인 시스템 페이지 (KO / EN) |
| `DESIGN.md` | 색·서체·그리드·컴포넌트·로고 규칙 원문. AI에게 첨부해 쓰는 파일 |
| `logo/` | 공식 로고 SVG — BCT 단독형·국문 병기형(color·white·black), 정사각형 마크(color·white) |

AI에게 문서·슬라이드·웹 페이지를 만들게 할 때 `DESIGN.md`를 첨부하고 "이 디자인 시스템을 따라 만들어 줘"라고 요청합니다.

원본 관리: `Brand Marketing/Design_System_BCT`, 로고 원본은 `Brand Marketing/Logo_bct`. 이 저장소는 게시용 사본입니다.
